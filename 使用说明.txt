一键黑屏 v9 使用说明
====================

【这是什么】
双击「一键黑屏」即可让所有已连接并启用的显示器被同一颜色覆盖（默认纯黑），
按任意键盘按键或点击鼠标任意键即可退出，所有屏幕一起恢复。退出交互与旧版完全一致。
v9 更新（对应程序版本 1.2.0）：更新自动检测、预下载与一键秒装覆盖升级；安装与数据位置可自定义；卸载零残留。
v8 更新（对应程序版本 1.1.0）：推荐 Setup 安装包安装；开始菜单新增「一键黑屏-设置」入口。
v7 更新（对应程序版本 1.0.2）：修复同时打开两个设置窗口、先后点击「立即更新」时
可能出现的更新失败（并发更新会自动排队，正常使用不受影响）。
v6 更新（对应程序版本 1.0.1）：修复极少数环境下遮罩无法退出的问题——个别
远程/自动化软件可能在系统里留下"幻影按键"状态，此前会永久阻断键盘/鼠标退出，
现约 1 秒后自动解除阻断；健康环境下行为与旧版完全一致。
v6 更新（对应程序版本 1.0.0）：新增「自动更新」与「空闲自动唤起」两项功能，
遮罩与退出交互与旧版完全一致（详见下方两节与隐私口径）。
v5 更新：设置窗界面风格统一（正文字号加大、区块标题加粗、间距按 4px 网格规整、
文字框加高、主按钮保持 Win11 蓝强调）；界面颜色与布局数值全部单一来源管理。
v4 更新：设置窗"遮罩文字"内按回车即换行（如标签所述，修复了回车误触发保存）；
设置窗界面精修（保存按钮为主操作样式、分组与间距重排、文字框加高、约束提示右置）。
v3 更新：遮罩中文换用微软雅黑字体链（更清晰）；设置窗口跟随系统深浅色；
主程序与设置快捷方式拥有专属图标。

【安装】
- 安装包版（推荐）：从 GitHub Releases 下载 Setup 安装程序，双击按向导完成安装；
  无需管理员权限，安装到当前用户目录，可在 Windows「设置 > 应用」中完整卸载。
- 便携版（备选）：下载 zip 解压到任意文件夹即用，无需安装。

【两种启动方式】
1. 「一键黑屏」（双击 exe，或安装版提供的开始菜单/桌面快捷方式）：立即出现全屏遮罩，
  绝不先弹设置界面。
2. 「一键黑屏-设置」（安装版开始菜单快捷方式，或命令行加参数 --settings）：
  打开设置窗口，自定义遮罩。

【图标说明】
- 主图标：深色圆角屏幕 + 月亮，代表"熄屏"。
- 设置图标：同款屏幕 + 右下角齿轮角标，代表"设置"。
- 图标为多尺寸格式（16~256px），任务栏/Alt-Tab/标题栏自动取合适档位。

【设置窗口能改什么】
- 遮罩颜色：点色块快速选（黑/深灰/深蓝/墨绿/暗红/白），或"自定义颜色…"任意选。
  当前选中的色块会显示蓝色加粗边框。
- 遮罩文字：最多 200 字，回车可换行（输入框内按 Enter 即换行；焦点不在输入框时
  按 Enter 才会保存），留空则不显示。文字颜色自动选黑或白，
  保证在底色上看清（WCAG 对比度规则），无需手动设置。
- 预览区按主屏比例实时显示效果（所见即所得）；预览与色块颜色只由你的配置决定。
- 自动唤起：选 关闭 / 5 / 10 / 15 / 30 分钟（默认关闭），详见下方【空闲自动唤起】。
- 窗口底部页脚：显示当前版本号（1.2.0）与「检查更新」按钮，详见下方【自动更新】。
- 按钮：恢复默认 / 取消 / 保存 / 保存并试用（保存后立刻启动一次遮罩供确认，
  按任意键退出预览）。

【空闲自动唤起】
1. 打开设置窗口，找到「自动唤起」。
2. 选择 5 分钟 / 10 分钟 / 15 分钟 / 30 分钟，点「保存」即开启；选「关闭」再保存即停用。
3. 效果：无任何键鼠操作达到所选时长后，所有屏幕自动出现遮罩；按任意键退出并重新计时。
4. 原理与隐私：由 Windows 计划任务（任务名 OneClickBlackScreen-Idle，仅属于当前用户）
   每分钟启动一次程序自检；未达时长会立即静默退出，不弹窗、不联网、无后台常驻。
   检测只读取本机"距上次键鼠操作的时间"（GetLastInputInfo），不记录任何操作内容。
5. 注意：锁屏/系统安全界面期间不会触发；合盖睡眠后任务随登录恢复；
   笔记本电池供电同样有效；任务只属于开启它的 Windows 账户，切换账户后需重新开启。

【自动更新】
1. 检查：打开设置窗口时会自动联网检查一次新版本（仅访问 GitHub 官方接口，不收集任何信息）；
   也可随时点窗口底部的「检查更新」手动查询。启动遮罩时，若距上次检查超过一天，
   也会静默补查一次（仅查询版本号，失败无任何提示）。
2. 发现新版本时：设置窗口自动在后台预下载新版并完成 SHA-256 校验（不打断正在做的设置），
   就绪后「立即更新」按钮亮起；同时遮罩右下角会低调显示一行「检测到新版本」提示。
3. 一键秒装：点「立即更新」即瞬间完成安装——安装包版为完整安装包覆盖更新
   （装完自动重启遮罩），便携版直接替换程序文件；配置与快捷方式都不变，
   完成后设置窗口自动关闭。
4. 校验与安全：下载文件会先做 SHA-256 校验，与官方发布不一致会拒绝安装，
   不会写入坏文件；更新失败（如断网）会显示失败原因，现有功能不受影响，可稍后重试。

【设置窗口跟随系统深浅色】
- 设置窗口的配色（窗口底色、按钮、文字、输入框）自动跟随 Windows 的
  应用深浅色设置（设置 > 个性化 > 颜色 > 模式）；切换深浅色时窗口约在
  半秒内自动刷新，无需重开。
- 边界（系统限制，如实告知）：
  · 设置中弹出的系统对话框（"自定义颜色"取色器、各类消息框）仍为系统
    浅色样式，不跟随深色，属 Windows 系统限制。
  · 高对比度主题是另一套独立体系，本程序不特殊适配。
  · 遮罩本身永远是你在设置里选的颜色，不受深浅色影响。

【保存后下次启动生效】
设置保存在：%LOCALAPPDATA%\BlackScreen\settings.ini（color= 与 text= 两行；
开启自动唤起后多一行 idle=；此为默认位置，安装向导或设置窗口的「数据位置」
可更改数据文件夹，更改时程序会自动迁移并校验数据）。遮罩启动时读取一次配置；
修改保存后，正在运行的遮罩不会变化，
下一次双击启动遮罩时才使用新设置。不想要配置文件时，直接删除它即回纯黑默认
（自动唤起随之回到关闭；若计划任务仍在，请先在设置中改回「关闭」并保存）。

【退出交互（与旧版完全一致）】
- 按任意键盘按键，或点击鼠标任意按键，即可退出。
- 只移动鼠标不会退出；滚动滚轮也不会退出（按下滚轮中键会退出）。
- 启动时若键盘或鼠标按键还没松开，先松开，再按键或点击鼠标即可退出。
- 遮罩运行时鼠标指针自动隐藏。

【边界与风险（如实告知）】
- 程序只覆盖画面，不关闭显示器电源，不暂停正在运行的程序或声音。
- 无需管理员权限，无第三方依赖（安装包装到当前用户目录，或便携版解压即用）；
  空闲自检不联网、不修改系统设置
  （开启自动唤起仅注册一条当前用户的计划任务，可随时关闭删除；
  遮罩仅隔天静默查一次版本号，见下方隐私口径）。
- 隐私口径：打开设置窗口即联网检查更新（每次打开检查一次）；启动遮罩时隔天静默
  检查一次（仅版本号查询，失败无感）。请求只发往 GitHub 官方域名（api.github.com），
  不收集、不上报任何数据；空闲自检永不联网。
- 程序内更新下载不经浏览器，不触发 SmartScreen；杀毒软件实时扫描仍正常覆盖。
- 安全桌面/锁屏/UAC 提权界面无法被覆盖，空闲唤起在这些界面期间也不会触发；
  TopMost 窗体之间无绝对覆盖保证。
- "任意键"受系统保留组合限制；混合 DPI 副屏文字清晰度依赖每屏一窗渲染。
- 若遮罩已在运行，"保存并试用"启动的第二个实例会静默自退（单实例机制），
  先退出当前遮罩再试用即可。
- 传入未知参数时程序只弹用法提示，绝不进入遮罩。
- 卸载（安装包版）：在 Windows「设置 > 应用」（或"添加/删除程序"）中卸载「一键黑屏」，
  程序文件、快捷方式、自动唤起的计划任务与个人设置数据一并删除，卸载后无残留；
  确认弹窗会明确告知将同时删除个人设置数据（若登记的数据位置异常，
  为安全起见会保留数据并提示手动清理）。
- 卸载（便携版）：先在设置中把「自动唤起」改回「关闭」并保存（自动删除计划任务
  OneClickBlackScreen-Idle；或在"任务计划程序"中手动删除同名任务），
  再删除程序所在文件夹（主程序 exe、同名 .exe.config、icon-settings.ico）、
  快捷方式与配置文件（若曾在设置中更改数据位置，一并删除对应文件夹）即可完全移除。

【开发者提示】
仓库根：build.cmd 构建；verify.cmd 全量验证（八件套，设置窗验证 6 查＝回车行为第 5 查
+ 几何与主按钮镜像锁定第 6 查；VerifyUpdate 为更新全链路离线验证、VerifyIdle 为
计划任务与空闲判定验证、VerifyPaths 为数据目录解析与迁移演练验证）；
build-setup.cmd 打安装包（Inno Setup 脚本在 setup\，
版本号取自 src\AppInfo.cs）；tools\MakeIcon.cs 重新生成图标（显式运行后人工比对）。
开发过程文档见 docs\handoff\（历史轮次整目录归档在 archive\ 子目录）。
