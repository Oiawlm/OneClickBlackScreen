## 2. README 功能段（建议全文）

> **空闲自动唤起（可选，默认关闭）**
> 在设置窗口选择 5/10/15/30 分钟：无键鼠操作达到所选时长后，所有屏幕自动出现遮罩；按任意键退出，计时重新开始。由 Windows 计划任务每分钟静默自检驱动——**无后台常驻进程、不联网、不需要管理员权限**。开启时会以当前用户身份注册名为 `OneClickBlackScreen-Idle` 的计划任务；改回「关闭」并保存即自动删除该任务。

## 3. 使用说明.txt 新增节（建议全文）

> 【空闲自动唤起】
> 1. 打开设置窗口（一键黑屏.exe --settings），找到「自动唤起」。
> 2. 选择 5 分钟 / 10 分钟 / 15 分钟 / 30 分钟，点「保存」即开启；选「关闭」再保存即停用。
> 3. 效果：无任何键鼠操作达到所选时长后，所有屏幕自动出现遮罩；按任意键退出并重新计时。
> 4. 原理与隐私：由 Windows 计划任务（任务名 OneClickBlackScreen-Idle，仅属于当前用户）每分钟启动一次程序自检；未达时长会立即静默退出，不弹窗、不联网、无后台常驻。检测只读取本机"距上次键鼠操作的时间"（GetLastInputInfo），不记录任何操作内容。
> 5. 注意：锁屏/系统安全界面期间不会触发；合盖睡眠后任务随登录恢复；笔记本电池供电同样有效。
