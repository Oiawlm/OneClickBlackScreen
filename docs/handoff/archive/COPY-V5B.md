## 功能说明（一段版）

设置窗口新增自动更新：打开设置窗口时会自动联网检查一次新版本（仅访问 GitHub 官方接口，不收集任何信息），窗口底部也会显示当前版本号，并可随时点击「检查更新」手动查询。发现新版本时，点击「立即更新」即可自动完成下载、SHA-256 校验与替换，完成后关闭设置窗口，下次双击主程序即是新版。整个过程不需要重新下载安装包，也不会改动你的任何配置。**遮罩功能本身永不联网**：双击出现的黑屏遮罩与退出交互和旧版完全一致，没有任何联网行为。

## 边界与隐私（拆条版，供「使用说明」边界节取用）

- 只有打开设置窗口才会联网检查更新（每次打开检查一次），遮罩模式永不联网。
- 更新下载自动校验 SHA-256，与官方发布不一致会拒绝安装，不会写入坏文件。
- 更新失败（如断网）会显示失败原因，窗口与现有功能不受影响，可稍后重试。
- 不收集、不上报任何数据；请求只发往 GitHub 官方域名（api.github.com）。
- 更新为单文件替换：未来若配置文件/图标也需随版本更新，将以新版更新方式另行说明。
